# Student & Inventory Management CLI System

A Python-based command-line interface (CLI) system designed to manage student or inventory records with persistent data storage using text files.

## Features
- **CRUD Operations**: Add, view, and delete records efficiently.
- **Data Persistence**: Automatically saves and loads records from a text file (`data.txt`) so data is never lost upon exit.
- **Clean Python Fundamentals**: Built using lists, dictionaries, functions, and file handling.
